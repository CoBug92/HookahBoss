# HookahBoss — рабочая спецификация MVP

`HookahBoss` — временное название нативного iOS-приложения для домашних любителей кальяна. Финальное название будет выбрано позднее.

## Ценность продукта

Приложение помогает:

1. Найти подходящий микс по вкусовым предпочтениям.
2. Понять, какие миксы можно собрать из имеющихся дома табаков.
3. Быстро сохранить понравившийся личный микс.
4. Вести избранное, запасы и оценки в одном месте.
5. Читать редакционные материалы по кальянной тематике.

## Границы MVP

- Нативный SwiftUI-клиент, ориентированный на iPhone и iOS 17+.
- Русская и английская локализации.
- Анонимный просмотр официального каталога, статей и коллективных рейтингов.
- Sign in with Apple для личных данных и действий.
- При попытке выполнить личное действие без входа появляется контекстная нижняя шторка с Sign in with Apple; она объясняет конкретное действие и может быть закрыта без потери текущего экрана.
- После успешного входа приложение автоматически продолжает исходное действие: сохранение в избранное, оценивание, управление запасами или создание личного микса.
- Без входа вкладка личной коллекции показывает плейсхолдеры разделов и контекстную нижнюю шторку авторизации.
- При выходе локальный кеш личных данных не удаляется, но остаётся изолированным по идентификатору Apple-пользователя и недоступен другому аккаунту.
- В настройках аккаунта доступно полное удаление аккаунта и связанных серверных данных с подтверждением — это обязательное требование публикации в App Store.
- iOS передаёт одноразовый Apple authorization code вместе с identity token; сервер хранит provider refresh token только в зашифрованном виде. При удалении доступный Apple token сначала отзывается; временная ошибка отзыва сохраняет аккаунт для retry. Legacy-аккаунт без provider token удаляется с честным уведомлением о ручном управлении разрешением Apple ID.
- Собственный REST API на Node.js/TypeScript, PostgreSQL и Docker Compose на VDS.
- Локальный кеш каталога и личной коллекции; синхронизация при появлении сети.
- Без рекламы, подписки, покупок, уведомлений и пользовательских публикаций.
- Подтверждение возраста 18+ при первом запуске.
- Никаких продаж табака, ссылок на магазины и рекламных материалов производителей.

## Навигация

1. **Главная** — крупная атмосферная карточка «Микс дня», два быстрых действия «Подобрать микс» и «Из моих запасов», затем персональная лента «Вам может понравиться». «Микс дня» выбирается редакционно/алгоритмически из опубликованных миксов и не требует входа; персонализация усиливается после появления оценок и избранного.
2. **Миксы** — каталог, поиск и фильтры.
3. **Создать** — быстрая запись личного микса.
4. **Статьи** — редакционные материалы.
5. **Моё** (`My` в английской локализации) — личный центр пользователя: быстрые счётчики избранного и созданных миксов, превью запасов и переходы к полным спискам. Настройки открываются отдельной кнопкой и не являются основным содержимым вкладки.

### Администрирование

- Админский интерфейс реализуется нативно внутри iOS-приложения, без отдельной веб-админки и отдельного контейнера.
- Раздел полностью скрыт для обычных пользователей и становится доступен только после серверной проверки Apple ID по `ADMIN_APPLE_SUBJECTS`; одной локальной проверки недостаточно.
- Точка входа — отдельный визуально отделённый служебный блок «Администрирование» во вкладке «Моё»; он появляется только после положительной серверной capability-проверки. В настройках остаются выход и удаление аккаунта.
- Главный экран показывает сводку каталога и переходы к брендам/линейкам/вкусам, официальным миксам, статьям, источникам и запрещённым заменам.
- Создание, редактирование, публикация и архивирование выполняются через существующий защищённый Admin API; обязательные источники, локализации и сумма процентов валидируются сервером.
- Состав официального микса редактируется нативными компактными строками: выбор позиции табака, процент, удаление и изменение порядка перетаскиванием; внизу всегда видна итоговая сумма. Сырой JSON пользователю не показывается.
- Массив тегов продукта и структурные секции статьи используют такой же нативный принцип строк, а не JSON-поля.

## Подбор миксов

- Фильтры размещаются на одном прокручиваемом экране без аккордеонов и пошагового мастера.
- Вкусовые профили: ягодный, фруктовый, цитрусовый, десертный, напиточный, травяной, пряный.
- Ощущения: сладость, кислотность и свежесть со значениями «не важно / немного / выраженно».
- Крепость: лёгкая, средняя, крепкая.
- Исключаемые вкусы.
- После применения фильтров открывается отдельный экран выдачи, а не каталог с наложенными фильтрами.
- Результаты группируются как «Идеально подходит» и «Может понравиться», без псевдоточного процента совпадения.
- Ранжирование учитывает соответствие фильтрам, личные оценки и избранное, коллективный рейтинг и новизну.

## Режим «Из моих запасов»

- Состояния запаса: много, мало, закончился.
- В списке запасов строка позиции раскрывается по нажатию и показывает выбор из трёх состояний; в свёрнутом виде отображается текущее состояние.
- Выдача разделена на три самостоятельные секции: «Можно приготовить», «С близкой заменой» и «Не хватает одного».
- Внутри секций используются обычные карточки миксов; для замены показываются исходная и доступная позиции, а для неполного совпадения — недостающий вкус.
- Сначала ищется конкретная позиция, затем близкий вкус независимо от бренда.
- Близость определяется автоматически по тегам; администратор может запрещать неудачные пары.
- В MVP показывается только факт замены и две позиции, без текстового объяснения влияния на вкус.

## Миксы и оценки

- Официальный микс привязан к конкретным табакам и всегда содержит точные проценты.
- Личный микс требует только компоненты. Проценты, оценка и комментарий опциональны.
- Экран создания сразу показывает пустой состав, без отдельного стартового шага.
- Компоненты можно выбирать из официального каталога, личных позиций и текущих запасов через единый поиск.
- Если проценты введены только для части компонентов, оставшийся процент автоматически распределяется поровну между незаполненными компонентами; при сумме введённых значений больше 100% сохранение блокируется.
- Создание открывается модально. Вверху расположено необязательное название, ниже — состав как главный визуальный блок с горизонтальными карточками компонентов.
- На экране создания нет полей оценки и комментария; их поддержка в модели данных не требует показывать их при быстрой записи микса.
- При отсутствии процентов компоненты считаются равными долями, профиль помечается как примерный.
- Одна изменяемая оценка пользователя от 1 до 5 на официальный микс.

## Статьи

- Категории MVP: основы, приготовление, чаши и жар, уход, безопасность.
- Пользователь может добавлять статьи в закладки.
- Материалы публикуются от редакции приложения без отображения персонального автора.
- Главный экран раздела построен по схеме «категории прежде всего»: отдельные карточки всех пяти категорий, затем компактный список рекомендованных материалов.
- На карточке и экране чтения показывается примерное время чтения, но не дата публикации или обновления.
- Внизу статьи показываются 2–3 похожих материала.
- Экран чтения использует иммерсивную обложку: крупное изображение, категория, заголовок и время чтения внутри нижнего градиента; ниже располагается спокойная редакционная колонка текста.
- Наличие оценки означает, что пользователь пробовал микс; отдельного состояния «Пробовал» нет.
- Публичные текстовые отзывы отсутствуют.
- Пользовательские миксы остаются личными. Возможность публикации откладывается.

### Карточка микса в каталоге

- Каталог отображается сеткой в две колонки.
- Пропорция карточки — примерно `0,86`: компактнее исходного вертикального формата, но немного выше квадрата.
- Обложка занимает карточку целиком; внизу используется усиленный тёмный градиент.
- Название заметно крупнее остальных элементов, допускает перенос на несколько строк.
- Вкусы показываются небольшими облачками; коллективный рейтинг расположен слева снизу, крепость — справа снизу и начинается с большой буквы.
- Избранное обозначается только контурным или заполненным сердцем без фоновой подложки.
- При наличии личной оценки слева сверху показывается компактная плашка со звездой и числом.
- Цвет текста и фона плашки, а также верхней части градиентной рамки зависят от оценки `1–5`. К низу рамка переходит в чёрный цвет.
- Карточка без личной оценки не содержит плашку и использует нейтральную приглушённую рамку.

### Экран официального микса

- Верхняя часть — крупная атмосферная обложка с названием, вкусовыми облачками, кнопкой возврата и сердцем избранного.
- Под обложкой в одной строке находятся коллективный рейтинг, автоматически рассчитанная крепость и личная оценка.
- При отсутствии личной оценки показывается действие «Оценить»; после оценки — звезда и число.
- Нажатие на личную оценку открывает нижний лист с выбором `1–5`; оценку можно изменить.
- Состав расположен горизонтально в виде одинаковых компактных мини-карточек: процент сверху, ниже бренд, линейка и название вкуса.
- Карточки компонентов неинтерактивны и не показывают состояние личных запасов.
- На экране нет действия массового добавления компонентов в запасы.

## Автоматический профиль

- Крепость задаётся для линейки табака.
- Конкретная позиция содержит вкусовые теги и значения сладости, кислотности и свежести.
- Профиль микса рассчитывается автоматически с учётом процентов компонентов.
- Администратор не задаёт итоговые характеристики микса вручную.

## Контент

- Стартовая база ориентирована на Россию и СНГ.
- Цель: 10–15 брендов, 150–250 вкусов, 40–60 официальных миксов и 8–12 статей.
- Включаются актуальные и архивные позиции с явной маркировкой.
- Данные и рецепты собираются из открытых интернет-источников; для каждой записи сохраняются источник и дата проверки.
- Импортированные тексты нормализуются и переводятся, а не копируются дословно.
- Коллективные рейтинги начинаются с нуля, без искусственных оценок.

## Визуальная система

- Тёмная тема: графитовая премиальная основа.
- Светлая тема: тёплая кремовая основа.
- Тема автоматически следует системной настройке iOS; отдельный ручной переключатель в MVP не нужен.
- Золотистый основной акцент и умеренные вкусовые цвета.
- Обложки официальных миксов: ингредиенты на атмосферном абстрактном фоне.
- Обложки личных миксов генерируются мгновенно из дизайн-шаблонов по вкусовым тегам, без AI-генерации и загрузки фотографий.

## Риск публикации в App Store

- Apple App Review Guideline 1.4.3 запрещает приложения, которые поощряют употребление табачных и вейп-продуктов, а также приложения, содействующие продаже табака: https://developer.apple.com/app-store/review/guidelines/#physical-harm
- Поскольку основная функция HookahBoss — подбор и создание табачных миксов, существует существенный риск отклонения даже при отсутствии продаж, рекламы и ссылок на магазины. Экран подтверждения возраста сам по себе этот риск не устраняет.
- Для публикации необходимо честно указать частые упоминания табака в анкете возрастного рейтинга App Store Connect; на новых версиях ОС это соответствует категории 18+, а на более ранних — 17+: https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions
- До подготовки релиза нужно отдельно выбрать стратегию распространения и, если используется App Store, сформулировать продукт как справочно-каталожный инструмент без призывов к употреблению; гарантии прохождения ревью это не даёт.
